% Modelled line for line on card_oct_sphere.tex: same macros, same pose
% {60}{120}, and \PanelScale 2.47 --- Figure 1.1's own scale, on all five
% cards.  At 2.47 the band is 175.01pt and the panel 158.40 x 157.60bp,
% beside the two ten-row vertex blocks, and the minimum projected chip
% separation is 36.84pt against a 9.5pt chip and a 19pt floor; assertion 21
% re-measures it at whatever scale is emitted, so a shrink that broke
% legibility would fail the build rather than ship.  The panel block itself
% --- halo widths, the thirty \drawEdge's and the twenty \drawDisk's in
% Figure 2.2's own order --- is copied verbatim from the dodecahedron panel
% of platonic_solid_povms.tex.  That panel draws DISKS and no rays,
% deliberately: a twenty-fold starburst dominates the polytope.
% \PanelFooter is not used --- the solid's name is the card's title.
%
% Chips: TEN, one per vertex axis, at the near end.  This is the panel the
% near-end rule exists for.  All twenty chipped, the minimum
% projected chip separation is 7.72pt against a 9.5pt chip --- six pairs
% overprint outright, and no rescaling fixes it because it is the pose; at the
% near end of each axis the minimum is 36.84pt.  Every colliding pair is one
% near and one far vertex, so the near-end rule removes the whole class rather
% than nudging its symptoms, and a hand nudge is a drawing decision the
% generator could not check.  The card's identities note states the rule in
% prose, the preamble already draws far-side disks grey at 0.85x and near-side
% black, and the vertex table prints all twenty tuples.
%
% The three grey axis names ARE drawn (measured: nearest chip centre to an axis
% anchor at radius 1.10 is 17.34pt here, against the octahedron's 2.67pt).
%
% Vertex 1 points nearly at the camera (v.view = 0.972, projected radius
% 16.6pt), so its chip takes the larger 11pt offset --- Figure 1.1's own
% remedy for the tetrahedron's vertex 1, the same geometry.
